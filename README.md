# cyclone-cn15-team02

Учебный макет циклона ЦН-15: влияние расхода воздуха на долю массы частиц,
собранную в пылесборнике. Ноябрь–декабрь 2026.

## Что проверяем
Изменяемый фактор: расход воздуха Q, три измеренных режима.
Основной показатель: eta_sb = m_sb / m_pod.
Дополнительно: перепад давления на циклоне dP_c.
Геометрия циклона и партия частиц неизменны.
